# Q002: C++ 对象生命周期

## 1. 概述

C++ 中每个对象都有一个**生命周期（lifetime）**，从构造完成到析构开始。理解对象的生命周期是正确使用 RAII、管理资源、避免悬空引用和内存泄漏的基础。

```
┌───────────────┐      ┌──────────────────┐      ┌───────────────┐
│  分配内存      │ ──→  │  调用构造函数     │ ──→  │  对象生命周期  │
│  (memory alloc)│      │  (constructor)   │      │  (active)     │
└───────────────┘      └──────────────────┘      └───────────────┘
                                                        │
                                                        ▼
                                              ┌──────────────────┐
                                              │  调用析构函数      │
                                              │  (destructor)    │
                                              └──────────────────┘
                                                        │
                                                        ▼
                                              ┌──────────────────┐
                                              │  释放内存        │
                                              │  (memory dealloc)│
                                              └──────────────────┘
```

## 2. 栈对象生命周期

栈对象是最常见、最简单的生命周期形式。

### 2.1 基本规则

```cpp
void func() {
    Test t;              // 默认构造（生命周期开始）
    do_something(t);     // 对象在作用域内可用
}                        // } 离开作用域 → 析构（生命周期结束）
```

### 2.2 构造顺序与析构顺序

**构造顺序 = 声明顺序，析构顺序 = 声明逆序（LIFO）**

```cpp
struct A { A() { std::cout << "A"; } ~A() { std::cout << "~A"; } };
struct B { B() { std::cout << "B"; } ~B() { std::cout << "~B"; } };

void func() {
    A a;           // 先构造 A
    B b;           // 后构造 B
}                  // 析构: ~B → ~A（逆序）

// 输出: AB~B~A
```

### 2.3 嵌套作用域

```cpp
void func() {
    A a;           // A 构造
    {
        B b;       // B 构造
    }              // B 析构（离开内层作用域）
    A a2;          // a2 构造
}                  // a2 析构 → a 析构
// 输出: AB~BA~A
```

### 2.4 栈对象特点

| 特性 | 说明 |
|------|------|
| ✅ **自动管理** | 进入作用域构造，离开作用域析构 |
| ✅ **高效** | 分配在栈上，速度极快 |
| ✅ **异常安全** | 栈展开保证析构 |
| ❌ **大小固定** | 栈空间有限（通常 ~8MB） |
| ❌ **不能返回** | 不能返回栈对象引用/指针给外层 |

## 3. 堆对象生命周期

堆对象需要手动管理，或借助 RAII 包装类。

### 3.1 手动管理

```cpp
void func() {
    Test* p = new Test();   // new: 分配内存 + 构造
    do_something(p);
    delete p;               // delete: 析构 + 释放内存
}
```

**问题：手动管理容易出错**

| 错误类型 | 示例 | 后果 |
|----------|------|------|
| 忘记 delete | 分支路径遗漏 | 内存泄漏 |
| 重复 delete | 两次 delete 同一指针 | 未定义行为 |
| 异常时泄漏 | delete 前的代码抛异常 | 内存泄漏 |
| 悬挂指针 | delete 后仍持有指针 | 未定义行为 |

### 3.2 借助 RAII 管理堆对象

```cpp
void func() {
    auto p = std::make_unique<Test>();  // unique_ptr 管理堆对象
    do_something(p.get());
}                                       // 自动 delete
```

### 3.3 new/delete 的完整流程

```
new Test:
  ┌─────────────────────┐
  │ operator new(sizeof(T))  ← 分配内存
  │   ↓
  │ T::T()                   ← 调用构造函数
  └─────────────────────┘

delete p:
  ┌─────────────────────┐
  │ p->~T()                 ← 调用析构函数
  │   ↓
  │ operator delete(p)      ← 释放内存
  └─────────────────────┘
```

## 4. 构造函数详解

### 4.1 构造函数的种类

| 类型 | 语法 | 说明 |
|:----:|------|------|
| **默认构造** | `T()` | 无参构造，`T t;` |
| **参数化构造** | `T(int)` | 带参数，`T t(42);` |
| **拷贝构造** | `T(const T&)` | 从同类型对象构造，`T t2 = t1;` |
| **移动构造** | `T(T&&)` | 转移资源所有权，`T t2 = std::move(t1);` |
| **委托构造** | `T(): T(0){}` | 一个构造调用另一个构造 |
| **转换构造** | `T(int)` | 支持隐式转换，可用 `explicit` 禁止 |

### 4.2 构造函数的执行顺序

```
构造一个派生类对象时：
① 基类构造函数（按继承顺序）
② 成员对象构造函数（按声明顺序）
③ 派生类构造函数体
```

```cpp
struct Base { Base() { std::cout << "Base "; } };
struct Member { Member() { std::cout << "Member "; } };
struct Derived : Base {
    Member m;
    Derived() { std::cout << "Derived "; }
};
// 输出: Base Member Derived
```

### 4.3 初始化列表 vs 赋值

```cpp
class Widget {
    const int id;         // const 成员必须用初始化列表
    std::string& name;    // 引用必须用初始化列表
    std::vector<int> v;   // 初始化列表更高效（避免默认构造+赋值）
public:
    Widget(int i, std::string& s)
        : id(i), name(s), v(100, 0)  // ✅ 初始化列表
    {
        // 构造体
    }
};
```

> **优先使用初始化列表**，它直接初始化成员；而赋值是"默认构造 + 再赋值"，效率更低。

## 5. 析构函数详解

### 5.1 基本规则

```cpp
~Widget() noexcept;  // 析构函数默认 noexcept
```

| 规则 | 说明 |
|------|------|
| ✅ **唯一** | 每个类最多一个析构函数 |
| ✅ **自动调用** | 栈对象离开作用域时自动调用 |
| ✅ **继承链** | 派生类析构后自动调用基类析构 |
| ❌ **不能抛出** | 析构函数必须 noexcept，否则风险极高 |
| ❌ **不能重载** | 不能有多个版本的析构函数 |

### 5.2 析构顺序

**析构顺序 = 构造顺序的逆序**

```
析构一个派生类对象时：
① 派生类析构函数体
② 成员对象析构（按声明逆序）
③ 基类析构函数（按继承逆序）
```

```cpp
struct Base   { ~Base()   { std::cout << "~Base "; } };
struct Member { ~Member() { std::cout << "~Member "; } };
struct Derived : Base {
    Member m;
    ~Derived() { std::cout << "~Derived "; }
};
// 输出: ~Derived ~Member ~Base
```

### 5.3 virtual 析构函数

当基类指针指向派生类对象时，析构函数必须是 virtual：

```cpp
class Base {
public:
    virtual ~Base() = default;  // ✅ 正确：保证正确析构派生类
};

class Derived : public Base { ... };

Base* p = new Derived();
delete p;  // 调用 ~Derived() → ~Base()（多态析构）
```

> 如果基类析构不是 virtual，`delete p` 只会调用 `~Base()`，导致派生类资源泄漏。

## 6. 生命周期总结

```
存储类型     分配位置    生命周期管理                   示例
──────────  ────────  ──────────────────────────  ────────────
栈对象        栈        自动（进入/离开作用域）        int x; Test t;
堆对象        堆        手动或 RAII                  new/delete; unique_ptr
全局/静态    静态区     程序启动 → 程序结束           static int i; 全局变量
局部static   静态区     首次访问 → 程序结束           void f() { static int i; }
临时对象      栈/寄存器   完整表达式结束                string("hello").size()
```

### 关键原则

1. **栈对象优先** — 能用栈就不用堆
2. **RAII 管理堆** — 堆对象必须由 RAII 包装类管理
3. **确定性析构** — C++ 的析构时机是确定的（与 GC 语言不同）
4. **Rule of Three/Five** — 如果定义了析构函数，通常也需要定义拷贝/移动操作
5. **避免悬挂引用** — 不要返回局部对象的指针/引用
