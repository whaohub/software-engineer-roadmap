## 双指针 (Two Pointers)

### 三种模式

| 模式 | 移动方向 | 适用场景 | 时间复杂度 |
|:----|:--------|:---------|:----------:|
| **左右指针** | 相向而行 | 有序数组 | O(n) |
| **快慢指针** | 同向而行 | 原地修改 | O(n) |
| **定一移二** | 固定 + 双向 | 多元素组合 | O(n²) |

### 题目框架

| # | 题目 | 难度 | 模式 | 核心思想 | 易错点 |
|:-:|:----|:----:|:----|:---------|:-------|
| LC 167 | 两数之和 II | 🟢 | 左右指针 | 和 < target 左移，> target 右移 | 数组必须有序 |
| LC 26 | 删除有序数组重复项 | 🟢 | 快慢指针 | slow 标记不重复位置 | 返回长度而非数组 |
| LC 27 | 移除元素 | 🟢 | 快慢指针 | slow 标记非 val 位置 | 元素顺序可变 |
| LC 283 | 移动零 | 🟢 | 快慢指针 | 非零往前放，末尾补零 | 保持非零元素相对顺序 |
| LC 11 | 盛最多水的容器 | 🟠 | 左右指针 | 移动**较短的边** | 面积公式 `(r-l)*min(h[l],h[r])` |
| LC 15 | 三数之和 | 🟠 | 定一移二 | 排序 + 固定 i + 双指针 | **三重去重** |

### 代码模板

**左右指针模板：**
```cpp
int left = 0, right = n - 1;
while (left < right) {
    // 根据条件移动 left 或 right
    if (condition) left++;
    else right--;
}
```

**快慢指针模板：**
```cpp
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (条件满足) {
        arr[slow++] = arr[fast];
    }
}
```

**定一移二模板：**
```cpp
sort(nums.begin(), nums.end());
for (int i = 0; i < n; i++) {
    int left = i + 1, right = n - 1;
    while (left < right) {
        int sum = nums[i] + nums[left] + nums[right];
        if (sum == target) { /* 记录并去重 */ }
        else if (sum < target) left++;
        else right--;
    }
}
```

## 滑动窗口 (Sliding Window)

### 两种模式

| 模式 | 说明 | 典型题 |
|:----|:-----|:-------|
| **可变窗口** | 右扩左缩，寻找最优解 | LC 3, 209, 424 |
| **固定窗口** | 固定大小滑动 | LC 438 |

### 题目框架

| # | 题目 | 难度 | 模式 | 核心思想 |
|:-:|:----|:----:|:----|:---------|
| LC 3 | 无重复字符的最长子串 | 🟠 | 可变窗口 | 哈希集合记录窗口内字符 |
| LC 209 | 长度最小的子数组 | 🟠 | 可变窗口 | 窗口和 ≥ target 时收缩 |
| LC 424 | 替换后的最长重复字符 | 🟠 | 可变窗口 | 窗口内最多替换 k 次 |
| LC 438 | 找到字符串中所有字母异位词 | 🟠 | 固定窗口 | 窗口字符计数匹配 |
