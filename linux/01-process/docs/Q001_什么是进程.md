# Q001: 什么是进程

## 1. 进程的定义

**进程（Process）** 是程序在计算机上的一次**执行活动**，是系统进行资源分配和调度的基本单位。

- **程序**：静态的指令序列 + 数据，存放在磁盘上，不占用运行资源
- **进程**：程序被加载到内存后动态执行时的实例，拥有独立的地址空间和资源

```bash
# 观察系统中的进程
ps -ef          # 全格式查看所有进程
ps aux          # BSD 风格
top / htop      # 动态查看
pstree -p       # 以树形展示进程父子关系
```

> 核心区别：**程序是"静态的图纸"，进程是"正在运行的机器"**。同一个程序（如 bash）可以对应多个进程。

---

## 2. PCB — 进程控制块

每个进程在内核中都有一个 **PCB（Process Control Block）** 与之对应，Linux 中即 `task_struct` 结构体。PCB 保存了内核管理该进程所需的全部信息：

| 分类 | 内容 |
|------|------|
| **进程标识** | PID（进程号）、PPID（父进程号）、PGID（进程组） |
| **进程状态** | R/S/D/T/Z 等运行状态 |
| **调度信息** | 优先级、调度策略、时间片 |
| **上下文** | CPU 寄存器值、程序计数器 PC（切换时保存/恢复） |
| **内存管理** | 代码段/数据段/堆/栈的虚拟地址空间（mm_struct） |
| **文件系统** | 打开的文件描述符表（files_struct） |
| **信号** | 信号处理函数、待处理信号集合 |
| **统计信息** | 启动时间、CPU 使用时间 |

> 一句话总结：**PCB 就是进程的"身份证+档案袋"**，内核通过它来管理每一个进程。

---

## 3. 进程 vs 程序

| 维度 | 程序 | 进程 |
|:----|:-----|:-----|
| **本质** | 静态指令集合 | 动态执行实例 |
| **存储** | 磁盘上的文件 | 内存中的运行态 |
| **生命周期** | 长期存在 | 创建 → 运行 → 终止 |
| **资源** | 不占用 CPU/内存 | 占用独立地址空间、CPU |
| **并发** | 无 | 一个程序可对应多个进程 |
| **对应关系** | 1 程序 | N 进程 |

```c
// 代码视角：同一份代码，可以运行出多个独立进程
#include <unistd.h>
#include <stdio.h>

int main() {
    for (int i = 0; i < 3; i++) {
        if (fork() == 0) {          // 子进程
            printf("子进程 PID=%d\n", getpid());
            return 0;
        }
    }
    // 父进程创建了 3 个子进程，但代码是同一份
    return 0;
}
```

## 4. 进程 vs 线程

| 维度 | 进程 | 线程 |
|:----|:-----|:-----|
| **资源** | 独立地址空间、独立资源 | 共享进程的地址空间 |
| **开销** | 创建/切换成本高 | 创建/切换成本低 |
| **通信** | 需 IPC（管道、共享内存等） | 直接共享全局变量 |
| **健壮性** | 一个崩溃不影响其他进程 | 一个线程崩溃可能导致整个进程退出 |
| **同步** | 需要跨进程同步机制 | 互斥锁、条件变量 |

> 进程是**资源分配**的基本单位，线程是**调度执行**的基本单位。

## 5. 进程的组成（内存布局）

一个进程在虚拟地址空间中由 4 个部分构成（从低地址到高地址）：

```
┌──────────────────────────┐ 高地址
│      内核空间 (1G)        │  ← 用户不可直接访问
├──────────────────────────┤
│      栈  Stack           │  ← 局部变量，向下增长
│          ↓               │
│          ↑               │
│      堆  Heap            │  ← malloc 动态分配，向上增长
├──────────────────────────┤
│      BSS 段              │  ← 未初始化全局变量（清零）
│      数据段 Data         │  ← 已初始化全局变量
│      代码段 Text         │  ← 只读指令
└──────────────────────────┘ 低地址
```

```bash
# 查看进程的内存映射
cat /proc/<PID>/maps
# 查看进程的环境变量和命令行
cat /proc/<PID>/environ
cat /proc/<PID>/cmdline
```

## 6. 进程状态（Linux）

| 状态 | 含义 | 说明 |
|:----:|:-----|:-----|
| **R** | Running/Runnable | 正在运行或在就绪队列中等待调度 |
| **S** | Sleeping | 可中断睡眠，等待某事件（最常见） |
| **D** | Disk Sleep | 不可中断睡眠，等待 IO，**无法被 kill** |
| **T** | Stopped | 停止，被信号暂停（如 Ctrl+Z / SIGSTOP） |
| **Z** | Zombie | 僵尸进程，已退出但未被父进程回收 |

```bash
# 查看进程状态列
ps -o pid,stat,comm
```

---

## 7. 面试要点总结

1. **一句话定义**：进程是程序的一次执行实例，是系统资源分配和调度的基本单位
2. **PCB 三要素**：PID、状态、上下文（寄存器 + PC）是必须能脱口而出的
3. **程序 vs 进程**：静态 vs 动态、磁盘 vs 内存、长期 vs 短生命周期
4. **进程 vs 线程**：资源分配单位 vs 调度单位；独立空间 vs 共享空间
5. **D 状态**：不可中断睡眠，`kill -9` 也杀不掉，常见于磁盘 IO 卡死
